Configurando .nanorc para edición rápida

Publicado en 2025

Una de las primeras configuraciones que realizo al instalar un nuevo sistema Linux es ajustar mis dotfiles y personalizar el editor de texto Nano para hacerlo más cómodo y moderno.

Configuración recomendada en ~/.nanorc

set linenumbers
set mouse
set tabsize 4
set tabstospaces
set constantshow

Explicación de las opciones

  • set linenumbers: Muestra números de línea a la izquierda.
  • set mouse: Habilita el soporte para posicionar el cursor con el ratón.
  • set tabsize 4: Ajusta la sangría de las tabulaciones a 4 espacios.
  • set constantshow: Muestra la posición de la línea y columna permanentemente.
