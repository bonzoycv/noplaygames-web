bat: un cat con superpoderes

Publicado el 9 de marzo, 2026

Como todo nuevo usuario al comenzar a usar cualquier distro Linux, comencé utilizando el comando cat para echar un vistazo rápido a archivos desde la terminal. Funciona, sí, es suficiente para este tipo de tareas rápidas, pero es bastante plano. Buscando y leyendo otros blogs un día encontré y probé bat. Es básicamente cat, pero con syntax highlighting, numeración de líneas e integración con git para mostrarte qué líneas cambiaron.

Instalación

En Arch Linux:

sudo pacman -S bat

En Fedora:

sudo dnf install bat

En Ubuntu / Debian:

sudo apt install bat

En Ubuntu y sus derivadas el binario se instala como batcat. Podemos solucionar esto creando un alias sencillo en Bash: 

echo 'alias bat="batcat"' >> ~/.bashrc
source ~/.bashrc

Ejemplos de uso

El uso básico es idéntico a cat:

bat archivo.py

Si quiero ver un script de bash o un archivo de configuración sin que pagine, uso --style=plain:

bat --style=plain ~/.bashrc

También lo uso dentro de un pipeline para aplicar color a la salida de otros comandos:

cat /var/log/syslog | bat -l log

Al recibir datos por pipe, bat no conoce la extensión del archivo original. Usando -l log le indicamos expresamente que aplique el resaltado sintáctico de archivos log.

Conclusión

El resaltado de sintaxis me ahorra esfuerzo al inspeccionar código rápidamente en la terminal. Por estos motivos bat es una de las primeras utilidades que instalo en cualquier sistema Linux.
