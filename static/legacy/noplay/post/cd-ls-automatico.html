Como modificar 'cd' para mostrar ls de manera automática

Publicado en 2026

Un patrón muy repetitivo en la terminal es cambiar de directorio con cd y de inmediato escribir ls para ver qué contenido hay dentro.

Podemos automatizar esta tarea sobrescribiendo el comando cd en nuestro ~/.bashrc usando una función sencilla: 

cd() {
  builtin cd "$@" && ls
}

¿Cómo funciona?

La palabra clave builtin cd ejecuta el comando nativo de Bash para cambiar de directorio. Si el cambio tiene éxito (&&), ejecuta ls inmediatamente.
